# ドット歩行テスト

見下ろし型2Dアクション用のキャラクター歩行テストです。キャラを選んで部屋を作るか部屋コードで入ると、最大4人で同じ画面を歩けます。

## 遊び方

1. キャラを選ぶ
2. 「新しい部屋を作る」→ 表示された4桁の数字の部屋コード（または招待リンク）を仲間に送る
3. 仲間はキャラを選んで部屋コードを入力、または招待リンクを開いて「入る」

通信は [PeerJS](https://peerjs.com/)（ブラウザ同士の直接通信）を使っています。部屋を作った人（親）が中継役なので、親が抜けると部屋は終了します。会社のネットワークなど一部の環境ではつながらないことがあります。

- 公開URL: https://shibata-yoshiyuki.github.io/test001/
- 操作: 画面をタップ（クリック）でその場所へ移動（歩いている途中にもう一度タップすると止まる）／押したまま上下左右にずらすとその方向へ移動／WASD・矢印キー
- プレイ画面は全画面。マップは周りを海に囲まれた島（72×54タイル）で、カメラが自分を中心に追います。海には入れません。

## ストーリーモード

部屋を作るときに「ストーリーモード」を選びます。お城の王様に頼まれて、北の魔王を倒しに行くお話です（全5章）。

- **歩いて進む**：場所の端（橋や石の道の先）まで歩くと画面が切りかわり、次の場所へ移動します。出口には行き先の看板があります
  - お城 ⇄ はじまりの村 ⇄ **草原**。草原がまんなかの広場で、ここから各地へ道がのびています
  - 草原から：西＝はじまりの村、北＝スライムの丘（第1章）・迷いの森（第2章）・もりかげ村、東＝ひだまり町（第3章）、南＝はかもり村・墓地（第4章）
  - 草原にはボスはいません。弱い敵が少しずつ出てきます
  - 章の場所へ続く道は**柵**でふさがれていて、ひとつ前の章のボスを倒す（自分のクリア記録がある）と通れます
  - 草原では**黄色い矢印**が、次に行く場所への出口を指します（画面上の表示にも「次の目的地」が出ます）
  - **魔王城（第5章）は草原からは行けません**。墓地のガイコツ大将を倒すと「もりかげ村の古井戸から地下道で行ける」とわかります。井戸に近づいて「しらべる」で魔王城へ
- **みんな別々の場所にいてOK**：1人は村で話を聞いて、もう1人は草原で戦う…ということもできます。参加者一覧に、それぞれの居場所が［ ］で出ます
- **村と村人**：3つの村と1つの町に村人がいます。近づいて「はなす」（スペースキー）で話が聞けます。ボスの攻撃のよけ方や、どの武器の番人がどの武器を落とすかなど、攻略のヒントもあります
- **襲われた町（第3章 ひだまり町）**：オークたちに襲われていて、家が燃えています。町の人は家に隠れていて、オーク隊長を倒すと出てきて話ができます
- **迷いの森は迷路**：分かれ道の多い迷路で、中では敵がどんどんわいてきます。奥に出口が2つあり、左上は「ゴブリンの巣」（第2章のボス、ゴブリンキング）、右上は「森の奥の広場」（武器の番人）です。行き止まり3か所に宝箱があります。2つはケーキかメロンソーダ、入口からいちばん遠い1つは**いのちのハート**（ライフの上限が1つ増え、記録に残ってずっと続く）です。宝箱は1人1回だけあけられ、あけた宝箱はその人にはもう出ません
- **ボスと武器の番人の見分け方**：ボスのいる場所への出口には赤い「⚠ BOSS」の看板、武器の番人の部屋への出口にはオレンジの「武器の番人」の看板が立っています。ボスが出ると赤い「BOSS」の表示が出て、画面上にボスの体力バーが出ます。頭の上の札も、ボスは「BOSS」、武器の番人は「武器の番人」です
- **武器の番人は別のマップ**：倒すと武器を落とす「武器の番人」は、各ダンジョンの先にあるマップにいます（倒さなくても先へ進めます）（スライムの丘→オーガのねぐら、迷いの森→森の奥の広場、墓地→墓地の奥）。いつでも行けます。魔王城は最後の場所なので武器の番人はいません
- **章の流れ**（迷路以外）：章の場所に入るとウェーブ（2〜3回）→ ボス → クリア。クリアすると光る門が出て、入るとお城に戻れます（町には門はありません）
  - その場にいる全員がクリア済みなら、敵は出ません（通り道として歩けます）。まだクリアしていない人が入ってくると、敵がまたやってきます
  - 全員が出て5秒たつと、その場所は最初の状態に戻ります

| 章 | 場所 | ボス | 武器の番人 | 落とす武器 |
|---|---|---|---|---|
| 第1章 スライムの丘 | スライムの丘 | キングスライム | オーガ | 刀 か 投げ斧 |
| 第2章 迷いの森 | 迷いの森（迷路）→ ゴブリンの巣 | ゴブリンキング | マスクオーク | 弓 か 赤い杖 |
| 第3章 襲われた町 | ひだまり町 | オーク隊長（たいまつを投げる・手下を呼ぶ） | なし | － |
| 第4章 さまよう墓地 | 墓地 | ガイコツ大将 | ゾンビ巨人 | 大ハンマー か 緑の杖 |
| 第5章 北の魔王城 | 魔王城 | 北の魔王 | なし | － |

- **進み具合**：章をクリアすると、**その場所にいた全員**にクリアが記録されます（遅れている人も一緒に戦えば追いつけます。ただし柵は自分の記録で開くので、先の章へ行くには一度その章をクリアする必要があります）
- **保存**：進み具合と持っている武器は、それぞれのブラウザに保存されます（別の端末・ブラウザには引き継がれません）。部屋を選ぶ画面に記録が表示され、「記録を消す」で最初からにできます
- **武器**：ストーリーでは雑魚敵は武器を落としません。各ダンジョンの先のマップで眠っている**武器の番人**を倒すと**武器を落とします**
  - 武器の番人はその場所に来た人数と同じ数だけ出ます（4人なら4体）
  - **武器の番人が落とした武器を拾えるのは、1つの場所で1人1つ**まで（残りは仲間のぶん）
  - 手に入れた武器は**回数制限なし・次の章にも持ち越し**。「持ちかえ」ボタンか Q キーで切りかえ
- **ダウン**：ウェーブを倒しきると復活。その場所にいる全員がダウンすると全滅し、お城で目を覚まします（クリア記録は消えません）
- **会話**：会話の文章は読み終わるころに自動で次へ進み、最後は自動で消えます（攻撃ボタン・スペースキー・会話の枠をタップで早送り）
- **エンディング**：第5章をクリアして光る門に入ると、王様のエンディングの会話があります

王様の絵は、素材集の魔法使い（wizzard_m）に王冠と赤い服を描き足したものです（`assets/story/king.png`）。

## モード

部屋を作るときに「ストーリー」「協力」「対戦」を選びます。

### 協力モード（ウェーブ制）
- 敵が波（ウェーブ）になって押し寄せます。**全4ウェーブ**。WAVE 4 のボス（魔王）を倒すと**ゲームクリア**（クリアタイムと各自の撃破数を表示し、15秒後に WAVE 1 からもう一度）
- 各ウェーブは「通常の敵を全部倒す → 最後にボスが1体だけ出る（このとき通常の敵は出ない）→ ボスを倒すとクリア」の流れです
- ボスはそのウェーブの敵を大きくしたもの（3倍。魔王だけ2倍）。攻撃の前には頭の上に「！」が出ます

| WAVE | ボス | 体力（1人） | 行動 |
|---|---|---|---|
| 1 | キングスライム | 14 | プレイヤーめがけて飛びかかる（着地点に赤い円）。着地の衝撃波と8方向弾。体力が2/3・1/3を切るたびに小さいスライム3匹に分裂 |
| 2 | ゴブリンキング | 16 | 赤い線で予告してから一直線に突進。突進後はフラフラ（攻撃のチャンス）→ 短剣を3本投げる。体力半分以下で間隔が短く、短剣5本に |
| 3 | ガイコツ大将 | 20 | 立ち止まってうずまき状に弾を連射（体力半分以下で3方向）。約11秒ごとに手下のガイコツを2体呼ぶ |
| 4 | 魔王 | 48 | 6つの攻撃を順に繰り返す：二重の全方位弾 → 速い扇形弾 → うずまき弾 → 火の玉（足元が赤く光って1秒後にはじける）→ ねらい撃ちの連射 → 消えて近くに瞬間移動（現れた所で全方位弾）。体力半分以下で怒り：攻撃の間かくが短くなり、弾が速く・多くなり、手下（まじない師・ガイコツ）を呼ぶ |

ボスの体力は人数で増えます（4人で2.5倍）。

- 味方の弾は味方に当たりません
- ダウンしたらそのウェーブ中は復活できません。ウェーブを倒しきると仲間の近くで復活し、生きている人はライフ＋1
- 全員が同時にダウンすると全滅。WAVE 1 からやり直し
- 敵の数は人数に合わせて増えます（1人で約1倍、4人で約2.5倍）

| 敵 | 出てくるのは | 体力 | 動き |
|---|---|---|---|
| スライム | WAVE 1〜 | 1 | ゆっくり追ってくる |
| ゴブリン | WAVE 2〜 | 1 | 速く追ってくる |
| ガイコツ | WAVE 3〜 | 3 | 追ってくる |
| まじない師 | WAVE 4〜 | 2 | 距離を取って紫の弾を撃つ |

敵と武器の画像は [0x72 DungeonTileset II](https://0x72.itch.io/dungeontileset-ii)（CC0）を使っています（`assets/enemies/LICENSE.txt`、`assets/weapons/LICENSE.txt`）。

### 対戦モード
- プレイヤー同士で戦います。ライフは3、どの武器でも1回当たると1減ります
- ライフ0でダウンし、3秒後に島のどこかで復活。倒した人の「撃破」が1増えます
- マップのどこかに時々（約9秒ごと、最大3個）武器が出ます

## 攻撃と武器

- 攻撃：画面右下のボタン（いま持っている武器の名前と残り回数が出ます）、スペース／J／Enter、PCは右クリックでカーソルの方向へ
- 最初は全員**ナイフ**。目の前2マスくらいしか届きません（回数制限なし）
- 落ちている武器に触ると拾えます。**20回**使うとナイフに戻ります
- 協力モードでは、ウェーブクリア時に人数分の武器が出るほか、敵がたまに落とします（ボスは2個）

威力はナイフを1として、遠くや広い範囲に届く武器ほど低く、近くでしか当たらない武器ほど高くしています（最大3）。対戦モードは今までどおり1発でライフ1つです。

| 武器 | 攻撃 | 威力（協力・ストーリー） |
|---|---|---|
| ナイフ | 目の前2マスを切る | 1 |
| 刀 | 前方を扇形になぎ払う（複数に当たる） | 2 |
| 大ハンマー | 少し溜めてから周り全体に衝撃波 | 3 |
| 投げ斧 | 7マスほど飛んでブーメランのように戻る。行きも帰りも当たる | 1 |
| 弓 | 速く遠くまで飛ぶ矢。敵を貫通 | 1 |
| 赤い杖 | 3方向に同時に撃つ | 0.5（1発あたり） |
| 緑の杖 | 近くの敵を追いかける弾 | 0.5 |

- 当たり判定・ライフ・武器の残り回数は、部屋の親（P1）のブラウザがまとめて判定します
- 部屋の親と入る人でページの版（`VERSION`）が違うと入れません。更新したら `index.html` の `VERSION` を変えてください（js ファイルも新しく読み直されます）

## マップ

- 周りを海に囲まれた島（72×54マス）。カメラが自分を中心に追います
- 右下の「見え方」ボタンで、ちかい／ふつう／ひろい の3段階に切り替え（最初は「ふつう」。選んだ段階はそのブラウザに保存されます）
- 木と岩は通り抜けられず、弾も止まります（隠れ場所になります）。投げ斧は当たると戻ってきます
- 木の後ろに入ると、その木が半透明になります
- 地形は全員同じです（固定の乱数で作っています）

## プログラムの構成

`index.html` は画面の部品（HTML）と見た目（CSS）だけで、プログラムは `js/` に役割ごとに分かれています。上から順に読み込まれ、あとのファイルは前のファイルのものを使えます。

| ファイル | 中身 | こんなときに見る |
|---|---|---|
| `index.html` | 画面の部品・見た目、`VERSION`（版）、js の読み込み | 更新したら `VERSION` を変える |
| `js/core.js` | 基本の設定、共通の道具、みんなで使う状態、お知らせ表示 | ライフの数、通信の間隔 |
| `js/data.js` | キャラ・武器（威力など）・アイテム・敵・ボスのデータと画像 | 武器の威力、敵の体力・速さ |
| `js/story-data.js` | 章・王様のセリフ・場所のつながり・村人のセリフ・マップの種類・記録 | セリフ、道のつながり、柵の条件 |
| `js/world.js` | マップを作る（島・迷路・村・お城）、木や岩の絵、当たり判定 | マップの形、迷路、宝箱の位置 |
| `js/lobby.js` | キャラ選び、部屋を作る／入る、参加者一覧 | 最初の画面 |
| `js/net.js` | 親（ホスト）と子の通信 | つながり方 |
| `js/combat.js` | 攻撃・弾・ダメージ・落ちている物を拾う | 攻撃の当たり方、拾うときの決まり |
| `js/enemies.js` | 敵・武器の番人・ボスの動き、協力モードのWAVE | ボスの攻撃パターン |
| `js/story.js` | ストーリーの進み方（場所ごとの戦い）、会話、移動、案内の矢印 | 章の流れ、会話の速さ |
| `js/input.js` | キーボード・ボタン・タップ・スティック・見え方 | 操作 |
| `js/render.js` | 画面に描く、毎フレームの処理 | 見た目、動き |
| `js/main.js` | 起動 | |

## つながらないとき

- 部屋の親がゲーム画面から**別のアプリやタブに切り替えると、全員の通信が止まります**（スマホは特に）。親は部屋コードを送ったら、すぐゲーム画面に戻ってください
- 15秒間通信がない人は、部屋から外れます
- 入るときは最大25秒待ちます。入れなかった場合は理由が表示されます
- 「ページの版が違います」と出たら、全員ページを再読み込みしてください

## スプライト

`assets/sprites/` にあります。

| ファイル | 内容 |
|---|---|
| `shibata_walk.png` | 柴田さん（手描き） |
| `cyber_walk.png` | サイバー（手描き） |
| `yami_walk.png` / `kitamura_walk.png` / `yamada_walk.png` / `shindo_walk.png` / `takeda_walk.png` / `kikuchi_walk.png` / `mabuchi_walk.png` | ヤミさん・北村さん・山田さん・新藤さん・武田さん・菊地さん・馬淵さん（正面絵から自動生成） |
| `*_walk.json` | コマ割り・アニメーション定義 |

- 1コマ 20×32px、背景透過
- 横4コマ × 縦4方向（上から 下・左・右・上）
- 4コマをそのままループ（8fps目安）。各行の1コマ目が待機ポーズ

自動生成キャラの横向き・後ろ姿は `tools/gen_chars.py` が正面絵（`source/characters/`）から作っています。
キャラを増やすときは、正面絵を置いて次を実行し、`index.html` の `CHARS` に1行足します。

```
python3 tools/gen_chars.py assets/sprites "source/characters/○○さん.PNG=id"
```

## アイテム素材（おまけ）

`assets/items/` にあります。使い道は未定のため、素材として取り込んであります。一覧は `items.html` で見られます。

- `other_XX.png` / `drink_XX.png` / `food_XX.png`：原寸ドット、余白なし（その他24・飲み物26・食べ物29）
- `items_atlas.png`：全アイテムを1枚にまとめた画像
- `items.json`：各アイテムのID・分類・サイズ・アトラス内の位置・元ファイル名
