# ドット歩行テスト

見下ろし型2Dアクション用のキャラクター歩行テストです。キャラを選んで部屋を作るか部屋コードで入ると、最大4人で同じ画面を歩けます。

## 遊び方

1. キャラを選ぶ
2. 「新しい部屋を作る」→ 表示された4桁の数字の部屋コード（または招待リンク）を仲間に送る
3. 仲間はキャラを選んで部屋コードを入力、または招待リンクを開いて「入る」

通信は [PeerJS](https://peerjs.com/)（ブラウザ同士の直接通信）を使っています。部屋を作った人（親）が中継役なので、親が抜けると部屋は終了します。会社のネットワークなど一部の環境ではつながらないことがあります。

- 公開URL: https://shibata-yoshiyuki.github.io/test001/
- 操作: 画面をタップ（クリック）でその場所へ移動／押したまま上下左右にずらすとその方向へ移動／WASD・矢印キー
- プレイ画面は全画面。マップは周りを海に囲まれた島（72×54タイル）で、カメラが自分を中心に追います。海には入れません。

## 対戦

- 攻撃：画面右下の「攻撃」ボタン、または スペース／J／Enter キー。押しっぱなしで連射（0.45秒間隔）
- 弾は最後に歩いた方向へ飛びます（斜めも可、射程は約9マス）
- ライフは3。1発当たると1減り、その後1秒は無敵（点滅）
- ライフ0でダウン。3秒後に島のどこかでライフ3に戻って復活。倒した人の「撃破」が1増えます
- 当たり判定とライフは部屋の親（P1）のブラウザがまとめて判定します

## スプライト

`assets/sprites/` にあります。

| ファイル | 内容 |
|---|---|
| `shibata_walk.png` | 柴田さん（手描き） |
| `cyber_walk.png` | サイバー（手描き） |
| `yami_walk.png` / `kitamura_walk.png` / `yamada_walk.png` / `shindo_walk.png` / `takeda_walk.png` / `kikuchi_walk.png` / `mabuchi_walk.png` | ヤミさん・北村さん・山田さん・新藤さん・武田さん・菊地さん・馬淵さん（正面絵から自動生成） |
| `*_walk.json` | コマ割り・アニメーション定義 |

- 1コマ 20×32px、背景透過
- 横4コマ × 縦4方向（上から 下・左・右・上）
- 4コマをそのままループ（8fps目安）。各行の1コマ目が待機ポーズ

自動生成キャラの横向き・後ろ姿は `tools/gen_chars.py` が正面絵（`source/characters/`）から作っています。
キャラを増やすときは、正面絵を置いて次を実行し、`index.html` の `CHARS` に1行足します。

```
python3 tools/gen_chars.py assets/sprites "source/characters/○○さん.PNG=id"
```

## アイテム素材（おまけ）

`assets/items/` にあります。使い道は未定のため、素材として取り込んであります。一覧は `items.html` で見られます。

- `other_XX.png` / `drink_XX.png` / `food_XX.png`：原寸ドット、余白なし（その他24・飲み物26・食べ物29）
- `items_atlas.png`：全アイテムを1枚にまとめた画像
- `items.json`：各アイテムのID・分類・サイズ・アトラス内の位置・元ファイル名
