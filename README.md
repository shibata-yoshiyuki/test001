# ドット歩行テスト

見下ろし型2Dアクション用のキャラクター歩行テストです。キャラを選んで部屋を作るか部屋コードで入ると、最大4人で同じ画面を歩けます。

## 遊び方

1. キャラを選ぶ
2. 「新しい部屋を作る」→ 表示された4桁の数字の部屋コード（または招待リンク）を仲間に送る
3. 仲間はキャラを選んで部屋コードを入力、または招待リンクを開いて「入る」

通信は [PeerJS](https://peerjs.com/)（ブラウザ同士の直接通信）を使っています。部屋を作った人（親）が中継役なので、親が抜けると部屋は終了します。会社のネットワークなど一部の環境ではつながらないことがあります。

- 公開URL: https://shibata-yoshiyuki.github.io/test001/
- 操作: 画面をタップ（クリック）でその場所へ移動／押したまま上下左右にずらすとその方向へ移動／WASD・矢印キー
- プレイ画面は全画面。マップは周りを海に囲まれた島（72×54タイル）で、カメラが自分を中心に追います。海には入れません。

## ストーリーモード

部屋を作るときに「ストーリーモード」を選びます。お城の王様に頼まれて、北の魔王を倒しに行くお話です（全4章）。

- **お城（集合場所）**：部屋に入るとお城の広間に集まります。王様に近づいて「はなす」で会話（自分の進み具合に合わせて話が変わります）。下の「出発の門」の前で「出発」を押すと行き先を選べます（選ぶのは部屋の親）
- **章の流れ**：会話 → ウェーブ（2〜3回）→ ボス → クリア。クリアすると真ん中に光る門が出て、入るとお城に戻ります

| 章 | 場所 | ボス | 寄り道の中ボス | 宝箱の武器 |
|---|---|---|---|---|
| 第1章 草原の異変 | 草原 | キングスライム | オーガ | 刀 か 投げ斧 |
| 第2章 ゴブリンの森 | 森 | ゴブリンキング | マスクオーク | 弓 か 赤い杖 |
| 第3章 さまよう墓地 | 墓地 | ガイコツ大将 | ゾンビ巨人 | 大ハンマー か 緑の杖 |
| 第4章 北の魔王城 | 魔王城 | 北の魔王 | オーク呪術師 | 6種からどれか |

- **進み具合**：章をクリアすると、**その場にいた全員**にクリアが記録されます（遅れている人も一緒に遊べば追いつけます）。行ける章は「部屋にいる中でいちばん進んでいる人」の次の章まで
- **保存**：進み具合と持っている武器は、それぞれのブラウザに保存されます（別の端末・ブラウザには引き継がれません）。部屋を選ぶ画面に記録が表示され、「記録を消す」で最初からにできます
- **武器**：ストーリーでは雑魚敵は武器を落としません。各章の寄り道（石の輪の広場）で眠っている**中ボス**を倒すと**宝箱**が出ます
  - 中ボスはその章に入った人数と同じ数だけいます（4人なら4体）
  - 宝箱1つで武器1つ。**1つの章であけられる宝箱は1人1つ**まで（残りは仲間のぶん）
  - 手に入れた武器は**回数制限なし・次の章にも持ち越し**。「持ちかえ」ボタンか Q キーで切りかえ
- **ダウン**：ウェーブを倒しきると復活。全員ダウンすると全滅し、お城に戻ります（クリア記録は消えません）
- **エンディング**：第4章をクリアして光る門に入ると、王様のエンディングの会話があります

王様の絵は、素材集の魔法使い（wizzard_m）に王冠と赤い服を描き足したものです（`assets/story/king.png`）。

## モード

部屋を作るときに「ストーリー」「協力」「対戦」を選びます。

### 協力モード（ウェーブ制）
- 敵が波（ウェーブ）になって押し寄せます。**全4ウェーブ**。WAVE 4 のボス（魔王）を倒すと**ゲームクリア**（クリアタイムと各自の撃破数を表示し、15秒後に WAVE 1 からもう一度）
- 各ウェーブは「通常の敵を全部倒す → 最後にボスが1体だけ出る（このとき通常の敵は出ない）→ ボスを倒すとクリア」の流れです
- ボスはそのウェーブの敵を大きくしたもの（3倍。魔王だけ2倍）。攻撃の前には頭の上に「！」が出ます

| WAVE | ボス | 体力（1人） | 行動 |
|---|---|---|---|
| 1 | キングスライム | 14 | プレイヤーめがけて飛びかかる（着地点に赤い円）。着地の衝撃波と8方向弾。体力が2/3・1/3を切るたびに小さいスライム3匹に分裂 |
| 2 | ゴブリンキング | 16 | 赤い線で予告してから一直線に突進。突進後はフラフラ（攻撃のチャンス）→ 短剣を3本投げる。体力半分以下で間隔が短く、短剣5本に |
| 3 | ガイコツ大将 | 20 | 立ち止まってうずまき状に弾を連射（体力半分以下で3方向）。約11秒ごとに手下のガイコツを2体呼ぶ |
| 4 | 魔王 | 36 | 全方位弾 → 扇形5方向弾 → 消えてプレイヤーの近くに瞬間移動、の順に繰り返す。体力半分以下で怒り（赤いオーラ）、攻撃が速く・弾が倍に |

ボスの体力は人数で増えます（4人で2.5倍）。

- 味方の弾は味方に当たりません
- ダウンしたらそのウェーブ中は復活できません。ウェーブを倒しきると仲間の近くで復活し、生きている人はライフ＋1
- 全員が同時にダウンすると全滅。WAVE 1 からやり直し
- 敵の数は人数に合わせて増えます（1人で約1倍、4人で約2.5倍）

| 敵 | 出てくるのは | 体力 | 動き |
|---|---|---|---|
| スライム | WAVE 1〜 | 1 | ゆっくり追ってくる |
| ゴブリン | WAVE 2〜 | 1 | 速く追ってくる |
| ガイコツ | WAVE 3〜 | 3 | 追ってくる |
| まじない師 | WAVE 4〜 | 2 | 距離を取って紫の弾を撃つ |

敵と武器の画像は [0x72 DungeonTileset II](https://0x72.itch.io/dungeontileset-ii)（CC0）を使っています（`assets/enemies/LICENSE.txt`、`assets/weapons/LICENSE.txt`）。

### 対戦モード
- プレイヤー同士で戦います。ライフは3、どの武器でも1回当たると1減ります
- ライフ0でダウンし、3秒後に島のどこかで復活。倒した人の「撃破」が1増えます
- マップのどこかに時々（約9秒ごと、最大3個）武器が出ます

## 攻撃と武器

- 攻撃：画面右下のボタン（いま持っている武器の名前と残り回数が出ます）、スペース／J／Enter、PCは右クリックでカーソルの方向へ
- 最初は全員**ナイフ**。目の前2マスくらいしか届きません（回数制限なし）
- 落ちている武器に触ると拾えます。**20回**使うとナイフに戻ります
- 協力モードでは、ウェーブクリア時に人数分の武器が出るほか、敵がたまに落とします（ボスは2個）

| 武器 | 攻撃 | 協力での威力 |
|---|---|---|
| ナイフ | 目の前2マスを切る | 1 |
| 弓 | 速く遠くまで飛ぶ矢。敵を貫通 | 1 |
| 投げ斧 | 7マスほど飛んでブーメランのように戻る。行きも帰りも当たる | 2 |
| 刀 | 前方を扇形になぎ払う（複数に当たる） | 2 |
| 大ハンマー | 少し溜めてから周り全体に衝撃波 | 3 |
| 赤い杖 | 3方向に同時に撃つ | 1 |
| 緑の杖 | 近くの敵を追いかける弾 | 1 |

- 当たり判定・ライフ・武器の残り回数は、部屋の親（P1）のブラウザがまとめて判定します
- 部屋の親と入る人でページの版（`VERSION`）が違うと入れません。更新したら `index.html` の `VERSION` を変えてください

## 食べ物と飲み物

| アイテム | 効果 | 出てくる場所 |
|---|---|---|
| ケーキ | ライフが1回復（ライフが満タンのときは拾えず、その場に残ります） | 協力：敵がたまに落とす（約8%）／対戦：マップに時々出る |
| メロンソーダ | 10秒間、足が1.6倍速くなる（右下に残り秒数が出ます） | 協力：敵がたまに落とす（約6%）／対戦：マップに時々出る |

- 対戦では約12秒ごとに、どちらかがマップに出ます（同時に最大2個）
- 絵は「おまけ」の food_04（半分に縮小した `pickup_food.png`）と drink_05（`pickup_drink.png`）

## マップ

- 周りを海に囲まれた島（72×54マス）。カメラが自分を中心に追います
- 右下の「見え方」ボタンで、ちかい／ふつう／ひろい の3段階に切り替え（最初は「ふつう」。選んだ段階はそのブラウザに保存されます）
- 木と岩は通り抜けられず、弾も止まります（隠れ場所になります）。投げ斧は当たると戻ってきます
- 木の後ろに入ると、その木が半透明になります
- 地形は全員同じです（固定の乱数で作っています）

## つながらないとき

- 部屋の親がゲーム画面から**別のアプリやタブに切り替えると、全員の通信が止まります**（スマホは特に）。親は部屋コードを送ったら、すぐゲーム画面に戻ってください
- 15秒間通信がない人は、部屋から外れます
- 入るときは最大25秒待ちます。入れなかった場合は理由が表示されます
- 「ページの版が違います」と出たら、全員ページを再読み込みしてください

## スプライト

`assets/sprites/` にあります。

| ファイル | 内容 |
|---|---|
| `shibata_walk.png` | 柴田さん（手描き） |
| `cyber_walk.png` | サイバー（手描き） |
| `yami_walk.png` / `kitamura_walk.png` / `yamada_walk.png` / `shindo_walk.png` / `takeda_walk.png` / `kikuchi_walk.png` / `mabuchi_walk.png` | ヤミさん・北村さん・山田さん・新藤さん・武田さん・菊地さん・馬淵さん（正面絵から自動生成） |
| `*_walk.json` | コマ割り・アニメーション定義 |

- 1コマ 20×32px、背景透過
- 横4コマ × 縦4方向（上から 下・左・右・上）
- 4コマをそのままループ（8fps目安）。各行の1コマ目が待機ポーズ

自動生成キャラの横向き・後ろ姿は `tools/gen_chars.py` が正面絵（`source/characters/`）から作っています。
キャラを増やすときは、正面絵を置いて次を実行し、`index.html` の `CHARS` に1行足します。

```
python3 tools/gen_chars.py assets/sprites "source/characters/○○さん.PNG=id"
```

## アイテム素材（おまけ）

`assets/items/` にあります。使い道は未定のため、素材として取り込んであります。一覧は `items.html` で見られます。

- `other_XX.png` / `drink_XX.png` / `food_XX.png`：原寸ドット、余白なし（その他24・飲み物26・食べ物29）
- `items_atlas.png`：全アイテムを1枚にまとめた画像
- `items.json`：各アイテムのID・分類・サイズ・アトラス内の位置・元ファイル名
