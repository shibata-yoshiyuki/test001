# ドット歩行テスト

見下ろし型2Dアクション用のキャラクター歩行テストです。ブラウザで開いてキャラを選ぶと、そのキャラで歩き回れます。

- 公開URL: https://shibata-yoshiyuki.github.io/test001/
- 操作: WASD または 矢印キー（スマホは画面下の十字ボタン）

## スプライト

`assets/sprites/` にあります。

| ファイル | 内容 |
|---|---|
| `shibata_walk.png` | 柴田さん 歩行シート |
| `chara2_walk.png` | chara2 歩行シート |
| `*_walk.json` | コマ割り・アニメーション定義 |

- 1コマ 20×32px、背景透過
- 横4コマ × 縦4方向（上から 下・左・右・上）
- 4コマをそのままループ（8fps目安）。各行の1コマ目が待機ポーズ

`index.html` は画像を埋め込んだ単体ファイルなので、それだけで動きます。
